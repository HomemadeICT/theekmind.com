# TheekMind Brand Guide

Source sheet: ![[Theekmind Branding.png]]
Version v1.0, Sept 2026. Source files: github.com/homemadeict/TheekMind

## Identity
- **Name:** TheekMind (capital T and M, one word)
- **Tagline:** Build the skills. Create the future.
- **Lockup tagline:** LEARN / BUILD / GROW
- **Intro line:** Hey, I'm Theekshana, welcome to TheekMind.
- **Web:** theekmind.com, blog at blogs.theekmind.com
- **Email:** theekmind@gmail.com

## Colour palette
| Name | Hex | Role |
|---|---|---|
| Navy | `#0F2D5B` | Primary |
| Blue | `#1E7FE0` | Brand colour |
| Leaf gradient | `#1E7FE0` to `#3BC0FF` | Brand logo only |
| Slate | `#647488` | Tagline and secondary text |
| Light | `#F8FAFC` | Background |
| Link | `#1566BB` | Links and body-copy accents on light backgrounds |

**Accessibility:** Blue is a brand colour, not a text colour. On light backgrounds use `#1566BB` or darker for links and copy. Slate is for tagline and secondary text at 14px or larger.

## Typography
- **Font:** Inter, then -apple-system, "Segoe UI", Roboto, sans-serif
- **Weights loaded:** 400, 500, 600 (wordmark Semibold, tagline Medium)

| Level | Size / line-height | Weight |
|---|---|---|
| H1 | 40px / 1.15 | 600 |
| H2 | 28px / 1.25 | 600 |
| H3 | 20px / 1.35 | 600 |
| Body | 16px / 1.6 | 400 |
| Small | 14px / 1.5 | 400 |

## Marks and sizes
- **Icon / badge:** avatars, apps, favicon. App icon sizes 512, 256, 128, 64px. Minimum 32px. Keep about 10% inset as safe area.
- **Horizontal lockup:** website header, letterhead, video, banner. Minimum width 220px.
- **Wordmark only:** email signature, footer, video credit. Minimum width 140px.
- **Lockup ratio:** badge diameter = X, gap from badge to wordmark = X/2, wordmark baseline aligns with the badge centre. Never rebuild the lockup by hand.
- **Clear space:** equal to the cap height of the "T" in the wordmark, on all four sides.
- **Variants:** full colour (default), inverted for light and dark backgrounds, black, white, inverse.

## Do not
- Stretch, recolour, rotate, add effects or add shadows to the logo
- Place it over busy or high-contrast photos, or on a gradient background
- Use Inter Regular for the wordmark
- Use the tagline lockup below 220px wide
- Place over photos unless on a low-detail area with 3:1 contrast

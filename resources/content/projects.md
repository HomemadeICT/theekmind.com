## Software

### Petty Cash Management System (CEB Haliela)
A desktop app built for the Ceylon Electricity Board, Haliela branch, to manage petty cash under strict business rules.
- Role-based access with 22+ permissions, an audit log, and database backup and restore
- Monthly reports in Sinhala and English, plus Excel export with live formulas
- A setup wizard so it installs as a standalone app

**Stack:** VB.NET (.NET 8), SQLite · [Code](https://github.com/HomemadeICT/Petty-Cash-Management-System-Standalone-Deployable-Desktop-App-)

### POS and Inventory Management System
A point of sale and inventory system, built as my NVQ Level 5 software project.
- Three roles: Admin, Inventory Manager and Cashier
- Products, categories, suppliers, and stock in/out with a full audit trail
- Cart-based checkout with receipts, plus low-stock, daily sales and stock movement reports
- Runs with one `docker-compose up`

**Stack:** PHP 8.2, MySQL 8, Bootstrap 5, Docker · [Code](https://github.com/HomemadeICT/NVQ-Level-5-POS-IMS)

### Certificate Management System with Selenium tests
Certificate tracking and verification by NIC, with an admin dashboard, tested end to end with Selenium WebDriver.

**Stack:** PHP, MySQL, Python, Selenium · [Code](https://github.com/HomemadeICT/Selenium-Automation-Mini-Project-PHP-Mysql-Project-Certificate-Management-System)

### PHP and MySQL micro projects
Small teaching projects: a school library system, an institute admission system, and a certificate system.

**Stack:** PHP, MySQL, HTML/CSS/JS · [Code](https://github.com/HomemadeICT/PHP-MySQL-Micro-Projects)

## Networking

### Networking Packet Tracer Labs
A hands-on networking practical book in Cisco Packet Tracer: 15+ labs, from a basic LAN to an 80-workstation enterprise network.
- DHCP, DNS, web and mail servers
- VLANs, inter-VLAN routing (router-on-a-stick), port security and Telnet
- Wireless and IoT integration
- A final enterprise network design with a cost estimate

**Tools:** Cisco Packet Tracer 8.1+ · [Code and .pkt files](https://github.com/HomemadeICT/networking-packet-tracer-labs)
